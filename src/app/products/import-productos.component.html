Instrucciones

Estructura del Excel

Tu archivo debe tener exactamente 7 columnas en este orden:

  • Nombre - Nombre del producto (mín. 3 caracteres)
  • Código - Código único del producto (mín. 2 caracteres)
  • Costo - Precio de costo (mayor a 0)
  • Precio Final - Opcional (se calcula automáticamente)
  • Stock Actual - Cantidad disponible (≥ 0)
  • Stock Mínimo - Cantidad mínima (≥ 0)
  • IVA - Porcentaje de IVA (opcional)

Tips Importantes

  • El archivo debe estar en formato .xlsx
  • Los códigos deben ser únicos en el sistema
  • Si el Precio Final no se especifica, se calcula como: Costo / 0.70
  • Los errores no afectan otros productos (importación transaccional)
  • Máximo 10 MB por archivo
  • Puedes importar cientos de productos en segundos

Validaciones Automáticas

Cada producto será validado automáticamente:

  • ✓ Nombre requerido, mín 3 caracteres
  • ✓ Código requerido, mín 2 caracteres, debe ser único
  • ✓ Costo requerido y mayor a 0
  • ✓ Stock Actual requerido, no puede ser negativo
  • ✓ Stock Mínimo requerido, no puede ser negativo
  • ✓ IVA opcional, no puede ser negativo
